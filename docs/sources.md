# Foundations and Attribution

- [CISA Secure by Design guidance](https://www.cisa.gov/securebydesign): customer security outcomes, transparency and leadership accountability. This toolkit applies those ideas to business discovery; it does not claim endorsement.
- [NIST SP 800-218, SSDF](https://csrc.nist.gov/pubs/sp/800/218/final): lifecycle practices and attention to recurring causes of vulnerabilities.
- [OWASP SAMM](https://owaspsamm.org/model/): organizing and improving software assurance practices. No formal maturity score is produced here.
- [John Kindervag, Authentic Zero Trust](https://www.sei.cmu.edu/documents/79/2022_500_001_887645.pdf): protect-surface and transaction-flow methodology.
- [George Finney interview](https://thecyberwire.com/podcasts/8th-layer-insights/45/transcript): practical explanation of the methodology.
- [NIST SP 800-207, Zero Trust Architecture](https://csrc.nist.gov/pubs/sp/800/207/final): no implicit trust based solely on network location or ownership, with authentication and authorization for resource access.
- [OWASP Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html): least privilege, deny by default and permission validation on every request.
- **Zero Trust Chains** is James Kittle's concept. “No decision inherits trust” is used here to examine consequential decisions across business workflows.

This release paraphrases principles and provides original templates. It is not an official standard, comprehensive control catalog or a legal applicability assessment. Later releases may add explicit mappings with framework versions and evidence requirements.
